# Addons Odoo 18

Déposer ici les addons compatibles avec Odoo 18.

- Un dossier de module par addon.
- Version du manifeste : `18.0.x.y.z`.
- Vérifier la compatibilité sur une instance Odoo 18 avant publication.
- Les règles d’accès et les fichiers de données doivent être déclarés dans le manifeste.
